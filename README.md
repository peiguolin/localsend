# 局域网聊天室（localsend-chat）

局域网内的网页聊天室：文本聊天、文件传输（200MB）、图片预览，以及**文件夹共享**——每个人都可以把自己电脑上的某个文件夹共享出去，其他人浏览、下载，也可以（经共享者允许后）往里上传。

## 聊天增强

- **@ 提醒**：输入 `@` 自动弹出成员补全（↑↓ 选择、Enter/Tab 确认、Esc 关闭）；被 @ 的人收到**整泡高亮 + 专属三连提示音 + 桌面通知"X 提到了你"**
- **引用回复**：右键任意消息 →「引用回复」，输入栏出现引用预览条；发出的消息带引用气泡，**点击引用可滚动定位原消息**（带闪烁高亮）
- **撤回消息**：右键自己的消息 →「撤回」（限 2 分钟内，服务器校验本人）；全员即时替换为"撤回了一条消息"；已撤回消息不可再被引用
- **代码块**：消息中 ```` ```lang ```` 围栏代码自动**语法高亮**（highlight.js 本地 vendor，离线可用，深浅色自动适配）+ 右上角**一键复制**；`` `行内代码` `` 同样支持

## 快速开始

```bash
npm install
npm start          # 默认端口 3000，PORT=8080 npm start 可改
```

启动后访问控制台输出的 `https://<局域网IP>:3000`。

> **首次访问**：服务使用自签名 HTTPS 证书（`certs/` 目录，首次启动自动生成），
> 浏览器会提示"连接不是私密连接"——点 **高级 → 继续访问** 即可。
> 必须用 HTTPS 是因为浏览器的文件夹共享能力（File System Access API）只在安全上下文下开放。

## 文件夹共享用法

**共享者**（共享自己电脑的文件夹）：

1. 必须用 **Chrome / Edge** 打开页面（Firefox / Safari 不支持）
2. 顶部切到「共享文件」→「+ 共享我的文件夹」
3. 可设置：共享名称、**访问密码（可选）**、**是否允许他人上传**
4. 在系统弹窗中选择要共享的文件夹（若开了上传，系统会再确认一次"允许编辑"）
5. **共享期间保持页面打开**；关闭/刷新页面共享即下线
6. 「管理」里可随时改名称、改/取消密码、开关写入；改密码后已进入的人需重新输密码

**访问者**（任何现代浏览器均可）：

1. 「共享文件」页看到所有人的共享，点「进入」（有锁的输密码）
2. 面包屑逐级浏览，点文件「下载」；若共享者可写，还能「上传到此目录」（重名自动加 `(1)`）

所有文件数据经由中心服务器中转、不落盘；共享者的浏览器只能访问其亲手选择的文件夹，路径穿越在句柄层面天然免疫，服务器侧另有净化与鉴权。

## 语音通话（WebRTC 多方）

**1:1 呼叫**：在右侧「在线成员」列表里把鼠标移到某个成员上，点击电话图标即可**呼叫对方**。

**多人通话**：

- **多选呼叫**：点击成员名字可多选（打勾），选好后点「发起通话 (N)」即可呼叫多个成员
- **群聊电话**：侧边栏顶部「📞 群呼」一键呼叫**所有在线成员**

通话采用 **WebRTC Mesh 全网状**架构——每个成员与房间内其他每位成员各建一条 P2P 连接（N 人 = N×(N-1)/2 条），音频不经过服务器中转，局域网内延迟极低；1:1 就是"多选 1 人"的特例。

- 被叫方收到来电弹窗 + 振铃，可**接听 / 拒绝**；主叫可随时**取消**
- 通话进行中其他人仍可接听**中途加入**；任意成员离开/挂断不影响通话，最后一人离开通话结束
- 通话中显示**成员名单 chips** 与人数、**静音**切换、通话时长
- 忙线 / 离线成员会被自动跳过并提示；一方断线自动离开房间
- 需要浏览器麦克风权限（HTTPS 安全上下文下自动可用；Chrome / Edge / Firefox / Safari 均支持）

信令协议：`call_user{targets}` / `incoming_call` / `call_ringing` / `call_accept` / `call_reject` / `call_end` + `room_member_joined` / `room_member_left` + `rtc_offer` / `rtc_answer` / `rtc_ice`（均带 roomId），全部经 Socket.IO 转发，服务端以发送者 socket.id 为准并校验收发双方同房间，客户端无法伪造身份。

## 实时白板

顶部切到「白板」即进入多人实时协作画布（任何浏览器均可）：

- 笔迹**边画边广播**（40ms 批量坐标点），局域网内其他人实时看到你落笔的过程
- 工具：6 色色板 + 自定义颜色、粗细滑块、橡皮（真实擦除）、撤销（仅自己的最后一笔）、清空（二次确认，全员同步）
- 坐标按画布归一化，不同窗口尺寸各自适配；高 DPI 屏自动清晰渲染
- 服务器保存完整笔迹历史（上限 1500 笔 / 20 万点，超限丢最旧），**后进来的人自动重放整块白板**；断线重连自动重新同步
- **多人实时光标**：所有人的鼠标位置以彩色光标 + 昵称标签实时可见（30fps 上报、服务器限频防刷），颜色由服务器按最少使用分配；移出画布/切走 Tab/断线自动消失，新加入者立即看到在线光标
- 服务端对颜色/粗细/坐标做校验钳制，非法数据无法污染画布

## 深色模式

顶栏右侧的月亮/太阳按钮一键切换深色 / 浅色模式：

- 整套深色配色基于 CSS 变量切换（`html[data-theme='dark']`），聊天、共享、白板、弹窗、通话界面全覆盖
- 未手动选择过时**跟随系统外观**（`prefers-color-scheme`）；手动切换后记住选择（localStorage）
- 主题初始化脚本在样式表加载前执行，刷新页面**无闪烁**
- 白板画布在深色模式下**保持白色画纸**——笔迹颜色对所有人一致，协作所见即所得

## 屏幕共享（WebRTC Mesh 广播）

顶部切到「屏幕共享」：

- 点「共享我的屏幕」→ 系统弹窗选择**整个屏幕 / 某个窗口 / 浏览器标签页**（可带声音，取决于系统与浏览器）；其他人点「观看共享」即可实时收看
- 走 **WebRTC P2P 直连**（信令经服务器转发，画面数据不经过服务器），局域网内低延迟高画质
- 全站同时**只允许一人共享**；共享者可看到实时观看者名单；观看人数上限 8 人（Mesh 拓扑下共享者为每位观看者独立编码，防过载）
- 点浏览器自带"停止共享"、页内"停止共享"、或共享者断线，都会自动全员结束；断线重连后状态自动同步
- 服务器对信令做角色校验：offer 只能来自共享者、answer 只能发给共享者、ICE 仅限共享者-观看者对，无法伪造/劫持他人的共享流
- 需 Chrome / Edge / Firefox / Safari 较新版本（`getDisplayMedia`，HTTPS 下可用）

## 已知限制

- 共享者标签页必须保持打开；刷新后需重新创建共享（暂未做句柄恢复）
- 上传进共享只能写到已存在的目录，不会自动创建新目录
- 共享文件下载暂不支持断点续传
- 语音通话为 **Mesh 全网状**架构，适合小规模多人（建议 ≤6 人，人数过多时每人上行带宽按 N-1 路增长）；通话各方需保持页面打开
- 白板撤销仅限自己的最后一笔；不同宽高比的窗口间画面会有轻微拉伸
- 屏幕共享同时仅一人；观看上限 8 人；共享者/观看者均需保持页面打开

## 结构

```
server.js            HTTPS 服务 + 聊天 + 上传下载 + 共享中转 + 通话信令 + 白板中继
public/client.js     聊天前端 + 语音通话 + 昵称编辑
public/share.js      共享面板 + 共享者本地代理（File System Access API）+ Tab 注册
public/whiteboard.js 实时白板（Canvas 绘制 + 笔迹广播/重放）
certs/               自签名证书（自动生成）
uploads/             聊天上传的文件（.meta.json 记录原始文件名）
```
