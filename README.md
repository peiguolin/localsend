# 局域网聊天室（localsend-chat）

局域网内的网页聊天室：文本聊天、文件传输（单文件最大 2GB）、图片预览，以及**文件夹共享**——每个人都可以把自己电脑上的某个文件夹共享出去，其他人浏览、下载，也可以（经共享者允许后）往里上传。

## 聊天增强

- **@ 提醒**：输入 `@` 自动弹出成员补全（↑↓ 选择、Enter/Tab 确认、Esc 关闭）；被 @ 的人收到**整泡高亮 + 专属三连提示音 + 桌面通知"X 提到了你"**；发 `@所有人` / `@all` / `@everyone` 可**提醒整个房间**（全员整泡高亮 + 金色 @全员 高亮 + 桌面通知"X @了所有人"）
- **消息时间分隔线**：聊天区自动按日期分组——跨天消息之间插入「今天 / 昨天 / 日期（跨年带年份）」的分隔线，翻历史也正确插入
- **语音消息**：输入栏麦克风按钮一键录音（浏览器内录，最长 5 分钟），显示录音时长与红点状态，可**取消**；停止即自动发送为带内嵌播放器的语音气泡（WebM/Ogg/M4A 自动归档到 `uploads/audio/`，断点续传同享）
- **引用回复**：右键任意消息 →「引用回复」，输入栏出现引用预览条；发出的消息带引用气泡，**点击引用可滚动定位原消息**（带闪烁高亮）
- **撤回消息**：右键自己的消息 →「撤回」（限 2 分钟内，服务器校验本人）；全员即时替换为"撤回了一条消息"；已撤回消息不可再被引用
- **代码块**：消息中 ```` ```lang ```` 围栏代码自动**语法高亮**（highlight.js 本地 vendor，离线可用，深浅色自动适配）+ 右上角**一键复制**；`` `行内代码` `` 同样支持
- **粘贴截图即发送**（桌面端）：任何地方截图/复制图片后回到页面直接 **Ctrl+V** 立即发送（走图片上传，在线预览）；纯文本粘贴不受影响；群聊弹窗打开时不接管
- **表情回应**：把鼠标移到任意消息上点 `🙂`，从常用表情板选一个（或直接点已有表情）即可回应；同一个人同一条消息点同一表情两次 = 取消；回应**实时广播**给房间全员（带已读人数与谁点的提示），并**落盘 SQLite**——刷新/重启后仍在
- **已读回执**：自己发的消息左下角显示 `✓`（已送达）；有成员看过（滚动到底部/切换房间即自动上报）后变为 `✓✓ N`，悬停显示"已读：谁"。已读状态为会话级，服务器重启后清零

## 数据持久化（SQLite）

**历史数据自动保存到宿主机**：服务器首次启动自动在项目目录创建 `data/chat.db`（SQLite，零配置），聊天消息、文件/图片记录、白板笔迹全部落盘；重启服务后历史自动恢复（进房自动加载最近 200 条 + 白板重放）。

- 顶部切到「**数据**」tab 打开数据面板：**消息/文件/白板/库大小统计**、**历史搜索**（关键词 / 昵称 / LIKE 匹配）、**导出备份**（下载整个 chat.db，拷走即备份）、**清空历史**（二次确认，连带白板）
- 撤回消息状态也持久化（重启后仍显示已撤回）
- 表结构预留 `room` 字段（当前统一 `main` 房间），为将来自定义群聊/分房间查询做好准备
- `data/` 已加入 `.gitignore`，聊天记录**不会**被推送到 GitHub

## 文件上传：自动分类归档 + 断点续传

- **自动分类归档**：上传的文件按类型自动存到 `uploads/<分类>/<日期>/` 子目录（如 `uploads/document/20260827/`、`uploads/image/20260827/`）。常见类型映射已内置：
  - `text`（txt/md/log/csv/json/xml…）、`document`（doc/docx/pdf/xls/ppt/odt…）、`archive`（zip/rar/7z/tar/gz…）
  - `image`（png/jpg/gif/webp…）、`audio`（mp3/wav/flac…）、`video`（mp4/mkv/avi…）、`code`（js/py/java/c/html…）
  - `program`（exe/msi/apk/deb…）、`font`（ttf/otf/woff…）、未识别归 `other`
- **上传队列（多文件）**：文件/图片可**连续多选、粘贴、拖拽**堆进托盘，逐个显示缩略图与独立进度条；可**逐项取消**（含清理服务端暂存分片）与**失败重试**（自动断点续传）；发送时多文件 + 配文 → 配文作为独立文字消息先发、文件各自上传，单文件 + 配文 → 图文同发
- **断点续传**：大文件自动切成 2MB 分片逐片上传；中途断网/失败**自动重试**（重新 init 拿已收分片清单，跳过已传部分续传）；刷新后重新选择同一个文件同样从断点继续（服务端暂存区 `uploads/.tmp/` 启动时自动清理）
- **单文件上限 2GB**（默认，可在「数据」面板配置卡改 `单文件大小上限`）：分片续传天然支持大文件，超出会被服务端拒绝（`LOCALSEND_MAX_FILE_MB` 可环境变量覆盖）
- **秒传（内容去重）**：上传前浏览器先算文件内容 SHA-256，服务端发现**内容已存在**（不限文件名）时直接复用原存储、零流量即时进聊天；合并完成后服务端还会再校验一次哈希，防止分片被篡改/传错
- **优雅退出**：宿主机 Ctrl+C / kill 时，先广播"服务器正在关闭"、中止进行中的传输、清理暂存区，再安全关闭数据库落盘退出（重启后数据完整）

## 群聊房间（自定义房间）

- **公共房**：一进来就在的大聊天室（所有人默认都在，room=`main`），消息全员可见
- **拉起群聊**：右侧「在线成员」里**多选成员** → 点「**＋ 拉起群聊**」→ 可选填群聊名称（默认自动命名，如"张三、李四"）→ 创建
- **自动加入**：被拉的人无需确认，群聊直接出现在其右侧「我的房间」列表
- **独立房间号**：每个群聊有独立 room（`g<随机>`），消息/图片/文件**只在房间内广播**，非成员收不到也查不到历史
- **房间持久化**：群聊房间与成员身份（clientId）存 SQLite，**服务重启后自动恢复**；聊天历史按房间保存，切换房间自动加载
- **未读角标**：不在当前房间时收到消息 → 该房间列表显示未读数
- **退出/解散**：成员可退出群聊；创建者退出即解散（历史消息仍留在服务器）
- **置顶消息**：房主（或宿主机）右键消息 →「置顶消息」，置顶条显示在标题栏下方，点击即可滚动定位原消息；置顶状态存 SQLite，重启不丢；再次置顶/取消置顶即刻全员同步
- **群公告**：房主（或宿主机）点标题栏「📢 公告」发布房间公告（≤500 字，全员可见、存 SQLite、重启不丢）；清空历史不会清掉公告，房主可随时更新或清除
- **房间分享（扫码加入）**：任何成员点标题栏「🔗 分享」→ 弹窗显示房间邀请链接 + **二维码**，扫码（或打开链接）即可自动入房发言，无需被拉；房主/宿主机可「重置邀请」让旧链接失效
- **权限模型**：公共房只有宿主机能管（置顶/公告/清空）；群聊房房主也能管；普通成员仅查看

## 手机端适配（≤720px 自动切换）

- **底部房间标签栏**：手机屏幕底部（输入栏上方）显示可**横向滑动**的房间标签（公共房 + 各群聊房），点一下即切换，未读红点直接显示在标签上
- **成员/房间抽屉**：顶栏新增 **☰ 按钮**，点开右侧滑出抽屉（在线成员 + 我的房间 + 拉起群聊 + 群呼），点遮罩或切房自动收起
- **长按消息**呼出引用/复制/撤回菜单（手机上无右键）
- 高度用 `100dvh` 适配浏览器地址栏伸缩；数据面板统计卡移动端自动变 2 列；白板画布限宽防截断

## 快速开始

```bash
npm install
npm start          # 默认端口 3000，PORT=8080 npm start 可改
```

启动后访问控制台输出的 `https://<局域网IP>:3000`。

> **首次访问**：服务使用自签名 HTTPS 证书（`certs/` 目录，首次启动自动生成），
> 浏览器会提示"连接不是私密连接"——点 **高级 → 继续访问** 即可。
> 必须用 HTTPS 是因为浏览器的文件夹共享能力（File System Access API）只在安全上下文下开放。

### 配置中心

所有配置集中在 `localsend.config.json`（不存在则用默认值；`localsend.config.example.json` 是模板，本机文件已 gitignore）。**宿主机**在「数据」面板底部有配置卡，可视化查看/修改并保存回该文件：

| 配置项 | 默认 | 说明 |
|---|---|---|
| `port` | 3000 | 服务端口（重启） |
| `uploadDir` / `dbFile` | 空 | 覆盖默认 `uploads/` 与 `data/chat.db` 位置（重启） |
| `localAddrs` | 空 | 宿主机地址白名单（默认回环 ∪ 本机网卡 IP；重启） |
| `fileTtlDays` | 30 | 文件保留天数，0=不限（重启） |
| `maxUploadMB` | 2048 | uploads 容量上限（重启） |
| `maxFileMB` | 2048 | **单文件大小上限（默认 2GB）**（重启） |
| `msgTtlDays` | 0 | 消息保留天数，0=永久（重启） |
| `remindTickMs` | 30000 | 日程提醒轮询间隔（重启） |
| `translateUrl` | 空 | 翻译引擎地址，`off`=关闭；**保存即时生效**（自动探测本机 5000 端口） |
| `translateGtx` | false | 允许谷歌免费端点回退（内容发第三方；重启） |

**优先级**：环境变量 > `localsend.config.json` > 默认值。环境变量仍可随时覆盖（测试/临时用途），变量名即上表旧名（`PORT`、`LOCALSEND_*`）。

## 文件夹共享用法

**共享者**（共享自己电脑的文件夹）：

1. 必须用 **Chrome / Edge** 打开页面（Firefox / Safari 不支持）
2. 顶部切到「共享文件」→「+ 共享我的文件夹」
3. 可设置：共享名称、**访问密码（可选）**、**是否允许他人上传**
4. 在系统弹窗中选择要共享的文件夹（若开了上传，系统会再确认一次"允许编辑"）
5. **句柄持久化**：创建共享时文件夹句柄 + 设置自动存入本机 IndexedDB——**刷新 / 误关页面后自动恢复共享**（浏览器已授权时直接恢复；权限降为"询问"时页面顶部提示一键恢复，点一下即可）；「管理 → 取消共享」才会彻底清除记录
6. 共享期间保持页面打开（刷新会短暂下线，但会自动恢复）；「管理」里可随时改名称、改/取消密码、开关写入；改密码后已进入的人需重新输密码

**访问者**（任何现代浏览器均可）：

1. 「共享文件」页看到所有人的共享，点「进入」（有锁的输密码）
2. 面包屑逐级浏览，点文件「下载」——走**下载管理器**：2MB 分段并发拉取（Range 断点续传，服务器返回 206 + Content-Range），支持**暂停 / 继续 / 取消**，逐文件显示进度；用 Chrome/Edge 时进度与已下数据写入 **OPFS（浏览器私有文件系统）**——**刷新 / 误关页面后再进共享页会自动恢复未完成的下载并续传**（已下段不重下）；若共享者可写，还能「上传到此目录」（重名自动加 `(1)`）

所有文件数据经由中心服务器中转、不落盘；共享者的浏览器只能访问其亲手选择的文件夹，路径穿越在句柄层面天然免疫，服务器侧另有净化与鉴权。

## 语音通话（WebRTC 多方）

**1:1 呼叫**：在右侧「在线成员」列表里把鼠标移到某个成员上，点击电话图标即可**呼叫对方**。

**多人通话**：

- **多选呼叫**：点击成员名字可多选（打勾），选好后点「发起通话 (N)」即可呼叫多个成员
- **群聊电话**：侧边栏顶部「📞 群呼」一键呼叫**所有在线成员**

通话采用 **WebRTC Mesh 全网状**架构——每个成员与房间内其他每位成员各建一条 P2P 连接（N 人 = N×(N-1)/2 条），音频不经过服务器中转，局域网内延迟极低；1:1 就是"多选 1 人"的特例。

- 被叫方收到来电弹窗 + 振铃，可**接听 / 拒绝**；主叫可随时**取消**
- 通话进行中其他人仍可接听**中途加入**；任意成员离开/挂断不影响通话，最后一人离开通话结束
- 通话中显示**成员名单 chips** 与人数、**静音**切换、通话时长
- 忙线 / 离线成员会被自动跳过并提示；一方断线自动离开房间
- 需要浏览器麦克风权限（HTTPS 安全上下文下自动可用；Chrome / Edge / Firefox / Safari 均支持）

信令协议：`call_user{targets}` / `incoming_call` / `call_ringing` / `call_accept` / `call_reject` / `call_end` + `room_member_joined` / `room_member_left` + `rtc_offer` / `rtc_answer` / `rtc_ice`（均带 roomId），全部经 Socket.IO 转发，服务端以发送者 socket.id 为准并校验收发双方同房间，客户端无法伪造身份。

## 实时白板

顶部切到「白板」即进入多人实时协作画布（任何浏览器均可）：

- 笔迹**边画边广播**（40ms 批量坐标点），局域网内其他人实时看到你落笔的过程
- 工具：6 色色板 + 自定义颜色、粗细滑块、橡皮（真实擦除）、撤销（仅自己的最后一笔）、清空（二次确认，全员同步）
- 坐标按画布归一化，不同窗口尺寸各自适配；高 DPI 屏自动清晰渲染
- 服务器保存完整笔迹历史（上限 1500 笔 / 20 万点，超限丢最旧），**后进来的人自动重放整块白板**；断线重连自动重新同步
- **多人实时光标**：所有人的鼠标位置以彩色光标 + 昵称标签实时可见（30fps 上报、服务器限频防刷），颜色由服务器按最少使用分配；移出画布/切走 Tab/断线自动消失，新加入者立即看到在线光标
- 服务端对颜色/粗细/坐标做校验钳制，非法数据无法污染画布

## 深色模式

顶栏右侧的月亮/太阳按钮一键切换深色 / 浅色模式：

- 整套深色配色基于 CSS 变量切换（`html[data-theme='dark']`），聊天、共享、白板、弹窗、通话界面全覆盖
- 未手动选择过时**跟随系统外观**（`prefers-color-scheme`）；手动切换后记住选择（localStorage）
- 主题初始化脚本在样式表加载前执行，刷新页面**无闪烁**
- 白板画布在深色模式下**保持白色画纸**——笔迹颜色对所有人一致，协作所见即所得

## 屏幕共享（WebRTC Mesh 广播）

顶部切到「屏幕共享」：

- 点「共享我的屏幕」→ 系统弹窗选择**整个屏幕 / 某个窗口 / 浏览器标签页**（可带声音，取决于系统与浏览器）；其他人点「观看共享」即可实时收看
- 走 **WebRTC P2P 直连**（信令经服务器转发，画面数据不经过服务器），局域网内低延迟高画质
- 全站同时**只允许一人共享**；共享者可看到实时观看者名单；观看人数上限 8 人（Mesh 拓扑下共享者为每位观看者独立编码，防过载）
- 点浏览器自带"停止共享"、页内"停止共享"、或共享者断线，都会自动全员结束；断线重连后状态自动同步
- 服务器对信令做角色校验：offer 只能来自共享者、answer 只能发给共享者、ICE 仅限共享者-观看者对，无法伪造/劫持他人的共享流
- 需 Chrome / Edge / Firefox / Safari 较新版本（`getDisplayMedia`，HTTPS 下可用）

## 数据管理与权限

「数据」面板提供历史搜索/统计/导出/清空。删除类操作有严格权限控制（服务器逐请求校验，前端按钮同步隐藏）：

| 操作 | 房主 | 普通成员 | 局域网其他人 | 宿主机（127.0.0.1） |
|---|---|---|---|---|
| 清空自己创建的群聊房记录 | ✅（房间标题栏「清空记录」） | ❌ | ❌（非成员不可见） | ✅ |
| 清空公共房记录 | — | — | ❌ | ✅ |
| 导出整个 SQLite 数据库 | — | — | ❌（403） | ✅ |
| 解散群聊房 | ✅ | — | ❌ | ✅ |

- 「宿主机」= 连接来源地址是回环地址或**本机任意网卡 IP**（即在运行 `npm start` 的那台机器上打开页面，无论用 `127.0.0.1` 还是局域网 IP 访问都算；可用环境变量 `LOCALSEND_LOCAL_ADDRS` 显式指定）
- 房主身份用浏览器持久 clientId 校验（换昵称不掉线；清浏览器数据会失去房主身份，由宿主机兜底）
- 「清空历史」只删**消息记录**（公共房仅公共房、房间仅该房间）；文件本体由下方的生命周期策略管理

## 日历

顶部切到「日历」：

- **月视图 / 年视图**：逐日展示**法定节假日与调休**（`休`红标 / `班`橙标，放假区间显示"假期第 N 天/共 N 天"）、**农历日期**、**二十四节气**、**传统节日**（春节/端午/中秋/七夕/腊八等，由本地农历库计算，完全离线）
- **节假日数据**：`src/holidays.json` 按国务院办公厅放假通知录入（当前含 2025、2026），每年底官方发文后补一年即可；未收录年份自动降级为"法定当日 + 传统节日"并提示
- **共享日程**：点任意日期可查看/添加日程（标题 + 可选时间 + 备注），月视图以圆点标记有日程的日子
  - 日程存 SQLite，重启不丢；按**房间隔离**（公共房日程 / 各群聊房日程，左上角切换）
  - 删除权限：创建者本人或宿主机（与其他管理操作同一套判定）
  - 变更实时广播，房间内其他人日历自动刷新
- **到点提醒**：日程可设"提前 10 分钟 / 30 分钟 / 1 小时 / 1 天"提醒，到点服务器向对应房间推送 `📅 日程提醒` 系统消息（触发一次即止；服务重启时过期 30 分钟以上的提醒静默跳过不刷屏；轮询间隔可用 `LOCALSEND_REMIND_TICK_MS` 调整，默认 30s）
- **一键拉会**：日程行内 📞 按钮，自动呼叫该日程所在房间的全部**在线**成员（复用多人语音房间，公共房日程=呼叫所有在线成员）
- **今日横幅**：聊天页顶部细条显示"日期 · 星期 · 农历 · 节气/传统节日"，节假日显示"🎉 XX假期 第 N 天/共 N 天"（调休日显示"今天调休上班"），并附今天最近一条公共房日程；每 30 分钟自动刷新

## 消息翻译（英 → 中）

右键（手机长按）任意外文文本消息 →「翻译成中文」，译文以附加块显示在气泡下方（原消息不变，可收起/展开）：

- **引擎：局域网自建 LibreTranslate**（开源、免费、内容不出网）。宿主机或局域网任意机器部署一次即可：
  ```bash
  docker run -d --name libretranslate -p 5000:5000 \
    --restart unless-stopped \
    -e LT_LOAD_ONLY=en,zh \
    libretranslate/libretranslate:latest
  ```
  `LT_LOAD_ONLY=en,zh` 只下载英中两个模型（约 200MB；不加会下载全语言约 3GB+），首次启动等模型下载完成（`/languages` 有响应即就绪）
- **配置（零配置优先）**：启动时服务器会**自动探测本机 `127.0.0.1:5000`** 的 LibreTranslate，发现即接入，无需任何配置；引擎在局域网**其他机器**时才需显式指定：
  ```bash
  npm start                                                  # 引擎在本机：零配置自动接入
  LOCALSEND_TRANSLATE_URL=http://192.168.x.x:5000 npm start  # 引擎在局域网其他机器
  LOCALSEND_TRANSLATE_URL=off npm start                      # 显式关闭翻译
  ```
  不可用时翻译入口自动隐藏，其他功能不受影响；`LOCALSEND_TRANSLATE_GTX=1` 可显式允许回退到谷歌免费端点（需外网，内容会发送到第三方，默认关）
- **共享缓存**：译文按原文哈希存 SQLite——同一文本全房间只翻一次，后来者秒出
- 已是中文的消息自动跳过入口（CJK 占比启发式）；每 IP 1 次/秒限速，引擎超时 10s

## 数据生命周期

上传文件与聊天记录不再是"只进不出"，由可配置的保留策略自动管理（每小时自动清扫，数据面板可「立即清理」）：

| 策略 | 默认值 | 环境变量 | 说明 |
|---|---|---|---|
| 文件保留期 | 30 天 | `LOCALSEND_FILE_TTL_DAYS` | 超期文件自动删除（消息保留，下载提示文件不存在——同微信"文件已过期"语义）；0=不限 |
| uploads 容量上限 | 2048 MB | `LOCALSEND_MAX_UPLOAD_MB` | 超限后按上传时间淘汰最旧文件（LRU）；0=不限 |
| 消息保留期 | 永久 | `LOCALSEND_MSG_TTL_DAYS` | 超期消息自动删除（其引用文件随后按孤儿清理）；0=永久 |
| 碎片清理 | 24 小时 | —（内置） | `.tmp` 未完成分片超期即删 |
| 孤儿文件 | 1 小时 | —（内置） | 磁盘上 meta 与 DB 均无记录的文件清理（至少存在 1h 才删，防误删上传中文件） |

另外：**撤回文件/图片消息会连带删除文件本体与元数据**。

数据面板可见：磁盘文件数/占用、当前保留策略；「立即清理」「导出备份」「清空历史」均仅宿主机可用。

**恢复备份**：停服后执行 `npm run restore -- <备份文件路径>`（校验 SQLite 文件头、自动备份当前库、清理 WAL 后替换），再 `npm start`。切勿在服务器运行时热替换 chat.db。

## 已知限制

- 上传进共享只能写到已存在的目录，不会自动创建新目录
- 语音通话为 **Mesh 全网状**架构，适合小规模多人（建议 ≤6 人，人数过多时每人上行带宽按 N-1 路增长）；通话各方需保持页面打开
- 白板撤销仅限自己的最后一笔；不同宽高比的窗口间画面会有轻微拉伸
- 屏幕共享同时仅一人；观看上限 8 人；共享者/观看者均需保持页面打开
- 历史消息仅在**宿主机**（运行服务的那台机器）上持久化，其他设备关闭浏览器后不保留本地副本；删除 `data/chat.db` 即清空全部历史
- **已读回执**为会话级信息（谁在线看过），服务器重启后清零，不跨会话持久化
- 共享**下载续传的跨刷新恢复**依赖浏览器 OPFS（Chrome / Edge）；Firefox / Safari 仍可下载，但刷新后不自动恢复（只能重新开始）
